# Proposal

## Why

FR-10-5（响应式移动端）是界面层最后一块长期挂 ⬜ 的拼图：11 屏移动设计稿（`docs/ui-design/prototype-mobile.html`）早已就绪，但页面在 <768px 下仍是桌面布局——236px 侧边栏挤压内容区、弹窗固定 400–520px 宽度在手机上溢出、按钮触摸目标偏小、团购详情的参团按钮藏在页面中部。手机访问体验形同不可用。

本变更做一次克制的移动适配：不重做页面，只补齐"手机上能用"的最低契约——底部导航、固定操作栏、可点的按钮、不溢出的弹窗。

## What Changes

- **底部 Tab Bar（<768px）**：`Dashboard.vue` 在窄屏隐藏侧边栏，改用底部导航（5 个以内主入口按角色分配：用户=首页/团购广场/我的订单/消息/我的；团长=首页/团购广场/我的团购/核销台/我的；管理员=首页/数据看板/商品管理/订单管理/我的），消息项带未读角标，`safe-area-inset-bottom` 适配全面屏
- **详情页固定操作栏**：团购详情页在窄屏把「立即参团」+ 拼团价固定到底部（桌面布局不变），滚动时不丢主操作
- **全局移动层（tokens.css）**：<768px 下弹窗统一 `92%` 宽度防溢出、默认按钮触摸目标 ≥44px（small 按钮例外保留表格密度）、消息盒同理
- **明确不做**：单独的移动端页面/路由、底部数字键盘（核销台仍用系统键盘）、图片懒加载优化、Tab Bar 手势返回

## Capabilities

### New Capabilities

- `responsive-ui`: 窄屏（<768px）可用性契约——底部导航可达、核心操作固定可达、弹窗不溢出、触摸目标达标

## Impact

- **前端**：`Dashboard.vue`（底部导航 + 窄屏布局）、`GroupBuyDetail.vue`（固定操作栏）、`styles/tokens.css`（移动全局层）；无新增依赖、无路由变化
- **后端**：无任何改动
- **验证**：`npm run build` + 浏览器 390px 视口实测（登录、Tab 导航、团购详情固定栏、弹窗宽度）
