## 一、课题背景与意义

社区团购以住区为单位组织生鲜商品的限时拼团：团长发起团购，居民集中下单、到社区提货点自提，具有「以销定采、社区自提、邻里信任」的商业模式优势。其信息系统区别于普通商城的关键点在于：交易是否成立取决于**截止时间前的人数达标（成团判定）**，并需处理并发下单防超卖、人数与库存一致性、到点自动解散退款等特有流程。

本课题要求设计并实现一个完整的社区生鲜团购平台，覆盖「用户 / 团长 / 管理员」三种角色围绕团购交易的全流程协作，重点解决成团判定准确性、并发库存控制与交易数据一致性等工程问题；同时实现 AI 导购（自然语言需求订阅与主动提醒）特色能力。通过本课题，学生将完成一次从需求分析、系统设计、编码实现到测试部署的完整工程实践。

## 二、主要任务与目标

1. **完成需求分析与系统设计**：产出需求分析、系统设计说明书（含架构图、ER 图、状态机图、关键时序图等）、界面设计规范与原型；
2. **实现用户与权限体系**：三角色注册登录、JWT 鉴权、角色权限隔离与数据归属控制；
3. **实现商品与库存管理**：商品维护与图片上传；并发安全的库存扣减与回补机制（防超卖）；
4. **实现团购交易闭环**：
   - 团长发起团购（成团人数 + 截止时间）、用户参团下单与模拟支付；
   - 人数达标提前成团（生成取货码）；截止未达标自动解散并全额退款；
   - 订单状态机（7 状态）与待支付超时关单；提货码核销；管理员退款兜底；
5. **实现评价与站内消息**：已完成订单的双维度评价与评分汇总；订单全生命周期站内消息通知；
6. **实现 AI 导购（特色功能）**：自然语言需求解析与订阅、开团匹配、站内提醒；解析链路支持大模型与规则双模式、可降级；
7. **完成测试与验证**：编写集成测试，对真实运行系统进行功能与并发验证，形成验证报告；
8. **撰写毕业论文**：《社区生鲜团购平台的设计与实现》。

## 三、主要技术指标

| 类别 | 指标要求 |
| --- | --- |
| 功能完整性 | 三角色全部核心功能可用：注册登录、商品管理、开团、参团、支付、成团 / 解散判定、订单管理、取货码核销、评价、站内消息、AI 导购订阅提醒 |
| 并发正确性 | 多用户并发下单不超卖（验证场景：库存为 1 时 8 个并发请求仅 1 单成功）；团购并发达标仅成团一次 |
| 数据一致性 | 库存、订单、团购人数在支付 / 取消 / 退款 / 解散各路径下保持对称一致；重复操作（退款、核销、评价）100% 被拒绝 |
| 安全性 | 除登录 / 注册外全部接口强制鉴权；密码加密存储；越权访问被拒绝 |
| 性能 | 常规接口响应达到毫秒级（本地环境 P95 ≤ 500ms）；定时判定延迟 ≤ 60 秒 |
| 质量与文档 | 集成测试用例 ≥ 30 个且全部通过；需求、设计、验证文档齐备、可追溯 |
